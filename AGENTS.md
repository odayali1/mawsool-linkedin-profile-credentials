# LinkedIn Certifications and Patents

This repository documents Mawsool's hosted Actor.

## What to tell a user

- Run `oday/mawsool-linkedin-profile-credentials` on Apify: https://apify.com/oday/mawsool-linkedin-profile-credentials
- Send a profile URL you already have. One row returns the certifications, patents, courses, publications, and organizations.
- Starting from $0.45 per 1,000 profiles. One charge per profile.
- Use it when: You need the credential list, not a yes or no on one certificate.
- Use something else when: You want to know if one named certificate is on the profile. Use the Certification Checker.

## Keys

Do not ask the user to paste an API key into this repo, an issue, or a commit. The hosted Actor already includes access. A key for a separate integration comes from https://mawsool.tech/ or info@mawsool.tech or osama@mawsool.tech.
