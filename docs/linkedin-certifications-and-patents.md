# Certifications and patents from a LinkedIn profile URL

Send a profile URL you already have. One row returns the certifications, patents, courses, publications, and organizations.

Starting from $0.45 per 1,000 profiles. One charge per profile.

Run it on Apify: https://apify.com/oday/mawsool-linkedin-profile-credentials. The hosted Actor already includes access. An API key for your own integration is at [mawsool.tech](https://mawsool.tech/) and [the docs](https://docs.mawsool.tech/). Questions: osama@mawsool.tech or info@mawsool.tech.

## When this is the right Actor

You need the credential list, not a yes or no on one certificate.

## When to use a different Actor

You want to know if one named certificate is on the profile. Use the Certification Checker.
